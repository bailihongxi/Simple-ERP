# 个人进销存管理系统

一个面向个人/小商户的本地进销存管理工具，数据全部保存在本地，无需联网、无需注册、无需部署，打开浏览器即可使用。

## 一、项目解决什么问题

- **小商户/个人店主**：进货、销售、库存、应收应付全靠脑子记或 Excel 记，容易出错、对账麻烦
- **数据安全顾虑**：不想把商业数据放到云端 SaaS，担心数据泄露或服务停服
- **轻量需求**：不需要复杂的多用户、多门店、手机 APP 等功能，只要一台电脑就能管
- **Excel 管理痛点**：多表关联难、库存算不准、利润算不清、查找慢

本系统用一个本地数据库文件保存所有数据，启动一个本地网页服务，通过浏览器操作，兼顾了 Excel 的简单直观和管理系统的自动化计算能力。

## 二、主要功能

### 1. 首页总览
- 今日/本月进货、销售、毛利、库存价值、应收、应付等指标卡片
- 低库存预警列表（缺口越大越靠前）
- 近期交易记录（采购+销售混合倒序，最近 10 条）
- 快捷操作按钮：快速进货、快速销售

### 2. 产品信息管理
- 基础字段：商品名称、品牌、型号、分类、单位、进货价、售价、当前库存、平均成本、默认供应商、低库存预警值、备注
- 支持按**商品名称、品牌、分类**筛选
- 库存低于预警值自动标红
- 有关联采购/销售/盘点记录的商品不可删除，防止误删

### 3. 供应商管理
- 基础信息：名称、联系人、电话、地址、备注
- 自动计算应付余额（赊账采购 - 已付款）
- 详情页查看历史采购记录和付款记录
- 支持一键付款核销

### 4. 客户管理
- 基础信息：名称、联系人、电话、地址、备注
- 自动计算应收余额（赊账销售 - 已收款）
- 详情页查看历史销售记录（含毛利）和收款记录
- 支持一键收款核销

### 5. 采购管理
- 单条录入：选择商品和供应商（支持搜索下拉，自动匹配 ID），输入数量、单价、付款方式
- 批量操作：复选框多选，一键批量删除（自动回退库存、重算平均成本）
- Excel 导入：下载模板 → 填写 → 批量导入（按商品名称、供应商名称自动匹配）
- Excel 导出：当前筛选结果一键导出
- 日期/供应商/商品关键词筛选
- 采购后自动增加库存、更新加权平均成本

### 6. 销售管理
- 单条录入：选择商品（下拉显示当前库存，库存为 0 标红并标注"无货"）、客户，输入数量、单价、付款方式
- 库存不足自动阻止销售并提示
- 批量操作：复选框多选，一键批量删除（自动回退库存）
- Excel 导入：下载模板 → 填写 → 批量导入（自动校验库存）
- Excel 导出：当前筛选结果一键导出
- 日期/客户/商品关键词筛选
- 销售后自动扣减库存，销售成本采用加权平均法，毛利自动计算
- 毛利为负自动标红

### 7. 库存管理
- 实时库存列表：当前库存、平均成本、库存价值、预警状态
- 支持按**商品名称、品牌、分类、低库存**筛选
- 库存盘点：手动调整库存，记录变动原因和备注
- 库存变动流水：采购入库、销售出库、盘点调整三种类型统一展示
- 库存总价值 = 当前库存 × 加权平均成本

### 8. 财务模块
- 收入/支出/净利润/毛利/应收/应付/销售总额 指标卡片
- 近 6 个月收入/支出/毛利趋势图
- 收付款记录明细，支持日期和类型筛选
- 毛利率自动计算

### 9. 数据备份与恢复
- 一键备份数据库文件
- 恢复前自动备份当前数据，防止误操作
- 备份文件列表管理，可删除

### 10. 通用特性
- 所有模块均支持 Excel 导入导出
- 操作结果 Toast 提示，删除二次确认
- 数据全部保存在本地 SQLite 数据库文件，刷新/关闭/重启不丢失
- 不登录、不联网、不云数据库、不部署

## 三、安装方法

### 环境要求
- Python 3.9 或更高版本
- macOS / Windows / Linux 均可

### 方式一：Mac 双击启动（推荐）
1. 下载或克隆项目到本地
2. 双击 `start.command` 文件
3. 脚本会自动检查 Python、安装依赖、启动服务并打开浏览器

### 方式二：命令行启动
```bash
# 进入项目目录
cd ERP

# 安装依赖
pip3 install -r requirements.txt

# 启动服务
python3 app.py
```

启动成功后，浏览器会自动打开 `http://localhost:5000`。

### 依赖清单
```
Flask==2.3.3
openpyxl==3.1.2
```

## 四、使用方法

### 快速上手流程
1. **录入基础数据**：先在「产品信息」里添加商品，在「供应商信息」「客户信息」里添加往来单位（也可以通过 Excel 批量导入）
2. **录入采购**：在「采购管理」新增采购，选择商品和供应商，输入数量和单价，库存自动增加
3. **录入销售**：在「销售管理」新增销售，选择商品（会显示当前库存）和客户，输入数量和单价，库存自动扣减，毛利自动计算
4. **查看库存**：在「库存管理」查看实时库存，库存不足会标红预警
5. **收付款核销**：在供应商/客户详情页点击付款/收款，核销应收应付
6. **查看财务**：在「财务信息」查看收支利润和趋势
7. **定期备份**：在「数据备份/恢复」里定期备份数据库

### 数据存储位置
- 数据库文件：`data/erp_data.db`
- 备份文件：`backups/` 目录下
- 这两个目录已加入 `.gitignore`，不会被提交到版本控制

### 加权平均成本说明
系统采用**加权平均法**计算销售成本：
- 每次采购后更新平均成本：新均价 = (原库存 × 原均价 + 本次采购数量 × 本次单价) ÷ (原库存 + 本次数量)
- 销售时成本 = 销售数量 × 当前加权平均成本，固化到销售记录
- 编辑/删除历史采购后，系统会按时间顺序重算该商品的平均成本
- 编辑/删除销售不改变平均成本，只更新本次销售的成本记录

## 五、输入输出示例

### 示例 1：新增采购
**输入**：
- 商品：海尔 BCD-520WGCFDM4G6U1
- 供应商：家电批发
- 采购日期：2026-08-13
- 数量：5
- 单价：3500.00
- 付款方式：赊账
- 备注：首批进货

**结果**：
- 该商品库存 +5
- 应付余额 +17500.00
- 如果是首次采购，平均成本 = 3500.00
- 如果之前有库存，平均成本按加权平均公式重算

### 示例 2：新增销售
**输入**：
- 商品：海尔 BCD-520WGCFDM4G6U1（当前库存: 5）
- 客户：长安街道
- 销售日期：2026-08-13
- 数量：2
- 单价：3990.00
- 付款方式：现结

**结果**：
- 该商品库存 -2（剩余 3）
- 销售总金额：7980.00
- 销售成本：7000.00（2 × 3500 平均成本）
- 销售毛利：980.00
- 应收余额不变（现结）

### 示例 3：库存盘点
**输入**：
- 商品：海尔 BCD-520WGCFDM4G6U1
- 盘点后库存：4
- 变动原因：盘点差异
- 备注：实物比账面少 1 台

**结果**：
- 库存从 3 调整为 4（变动 +1）
- 生成一条盘点调整记录
- 平均成本不变

### 示例 4：Excel 导入采购
**模板列**：商品名称*、供应商名称、采购日期*、数量*、单价*、付款方式(现结/赊账)、备注

## 七、技术栈

- **后端**：Python 3.9 + Flask 2.3.3
- **数据库**：SQLite 3（本地文件，无需额外安装）
- **前端**：原生 HTML + CSS + JavaScript（不引入前端框架）
- **Excel**：openpyxl 3.1.2
- **运行方式**：本地 Flask 服务 + 浏览器访问

## 九、注意事项

1. 本系统仅供个人或小商户内部使用，未做用户权限和网络安全设计，**请勿部署到公网**
2. 重要数据请定期使用「数据备份」功能备份
3. 数据库文件 `data/erp_data.db` 是所有数据的唯一存储，请妥善保管
4. 如需迁移数据，直接复制 `data/erp_data.db` 文件即可
