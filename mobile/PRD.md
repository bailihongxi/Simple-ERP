# 进销存手机版 PWA 产品需求文档（PRD）

## 一、产品目标和使用场景

### 1.1 产品目标
为进销存系统的用户提供一个可以在手机上随时查看数据的轻量级工具，无需打开电脑，即可快速查询产品、库存、采购、销售等信息。

### 1.2 使用场景
- **外出时查库存**：在外面跑业务时，掏出手机就能查某个商品有没有货、有多少
- **现场查价格**：客户问价时，手机上快速查售价和进货价
- **查看采购销售记录**：随时翻看历史采购、销售明细
- **数据随身携带**：把数据导入手机，走到哪查到哪

### 1.3 核心定位
- **只读查询工具**：手机端只看不改，所有增删改操作都在电脑端完成
- **离线可用**：导入一次数据后，没有网络也能正常使用
- **轻量快速**：打开就能用，操作简单，不需要学习成本

## 二、整体页面框架和导航结构

### 2.1 技术方案
- **形式**：PWA（渐进式网页应用）
- **部署**：GitHub Pages
- **数据存储**：浏览器 localStorage
- **数据来源**：从电脑端导出 JSON 文件，导入到手机端

### 2.2 底部导航（3 个 Tab）

| Tab | 名称 | 说明 |
|-----|------|------|
| 1 | 首页 | 搜索总览 + 快捷入口 + 搜索结果 |
| 2 | 产品 | 产品列表 + 库存/采购快捷入口 + 筛选 |
| 3 | 销售 | 销售统计 + 销售记录列表 + 筛选 |

### 2.3 其他页面（从快捷入口进入）
- **库存页**：从产品页顶部快捷入口进入
- **采购页**：从产品页顶部快捷入口进入
- **我的/设置页**：从首页右上角设置图标进入

### 2.4 页面跳转关系
```
首页 ──搜索──→ 搜索结果（产品列表）
  │
  └─右上角──→ 我的/设置页

产品页 ──顶部快捷入口──→ 库存页
  │
  └─顶部快捷入口──→ 采购页

销售页（独立页面）
```

## 三、首页的内容结构

### 3.1 顶部栏
- 左侧：页面标题"首页"
- 右侧：设置图标（点击进入"我的/设置页"）

### 3.2 搜索区域
- 大搜索框，占据主要视觉位置
- 占位文字："搜索商品名称..."
- 输入后实时显示搜索结果

### 3.3 快捷入口区域
- 4 个快捷入口卡片（2×2 布局）：
  - 产品信息
  - 库存查询
  - 采购记录
  - 销售记录
- 点击对应卡片跳转到对应页面

### 3.4 搜索结果区域
- 搜索前：显示"输入关键词搜索产品"提示
- 搜索后：显示匹配的产品列表（卡片式）
- 每个产品卡片显示：名称、品牌、分类、库存、售价
- 点击产品卡片可查看详情

## 四、每个模块的用途

### 4.1 首页
- **用途**：统一入口，快速搜索产品，快捷跳转到各模块
- **核心功能**：产品搜索、快捷导航

### 4.2 产品信息
- **用途**：查看所有产品的完整列表，按品牌、分类筛选
- **核心功能**：产品列表浏览、多维度筛选

### 4.3 库存查询
- **用途**：查看库存状况，包括库存数量、价值、低库存预警
- **核心功能**：库存统计、库存列表、低库存筛选

### 4.4 采购记录
- **用途**：查看历史采购记录，了解进货情况
- **核心功能**：采购统计、采购列表、日期/关键词筛选

### 4.5 销售记录
- **用途**：查看历史销售记录，了解销售情况和利润
- **核心功能**：销售统计、销售列表、日期/关键词筛选、毛利显示

### 4.6 我的/设置
- **用途**：数据管理和系统设置
- **核心功能**：数据导入、数据清除、数据概览、关于信息

## 五、每个模块第一版最必要的数据和操作

### 5.1 首页

**展示数据**：
- 搜索结果：产品名称、品牌、分类、当前库存、售价

**操作**：
- 输入关键词搜索产品（模糊匹配产品名称）
- 点击快捷入口跳转到对应页面
- 点击设置图标进入我的页面
- 点击搜索结果查看产品详情

### 5.2 产品信息

**展示数据**：
- 产品名称、品牌、型号、分类、单位
- 进货价、售价
- 当前库存、低库存状态

**操作**：
- 按品牌筛选
- 按分类筛选
- 上拉加载更多（如果数据多）
- 点击产品查看详情

### 5.3 库存查询

**展示数据**：
- 统计卡片：商品种类、库存总数量、库存总价值、低库存数
- 列表：产品名称、品牌、分类、当前库存、平均成本、库存价值、状态标签

**操作**：
- 按名称搜索
- 按品牌筛选
- 按分类筛选
- 只看低库存

### 5.4 采购记录

**展示数据**：
- 统计卡片：采购笔数、采购总金额
- 列表：商品名称、供应商、采购日期、数量、单价、总金额、付款方式

**操作**：
- 按日期范围筛选
- 按关键词搜索（商品名/供应商名）

### 5.5 销售记录

**展示数据**：
- 统计卡片：销售笔数、销售总金额、总毛利、总成本
- 列表：商品名称、客户、销售日期、数量、单价、总金额、成本、毛利、付款方式

**操作**：
- 按日期范围筛选
- 按关键词搜索（商品名/客户名）

### 5.6 我的/设置

**展示数据**：
- 数据概览：商品数、采购数、销售数、库存总价值、导入时间
- 关于：版本号、数据存储说明

**操作**：
- 选择 JSON 文件导入数据
- 清除所有数据（二次确认）

## 六、首页和每个模块之间的关系

### 6.1 首页是总入口
- 所有模块都可以从首页的快捷入口进入
- 搜索功能只在首页，搜索结果是产品列表

### 6.2 产品页是核心模块
- 库存和采购的入口放在产品页顶部
- 因为库存和采购都和产品强相关

### 6.3 销售页独立
- 销售作为底部导航的独立 Tab
- 因为销售是高频查询场景，需要快速访问

### 6.4 页面跳转规则
- 底部 Tab 之间可以自由切换
- 从产品页进入库存/采购页后，左上角有返回按钮
- 所有页面都可以通过底部导航回到首页

## 七、本地数据文件，备份和恢复要求

### 7.1 数据格式
- **格式**：JSON 文件
- **来源**：电脑端「备份」页面 → 「导出手机端数据」按钮生成
- **编码**：UTF-8

### 7.2 数据内容
JSON 文件包含以下数据：
- `version`：数据格式版本号
- `export_time`：导出时间
- `products`：产品列表（含库存、成本等）
- `purchases`：采购记录列表（含商品名、供应商名）
- `sales`：销售记录列表（含商品名、客户名、成本、利润）
- `suppliers`：供应商列表（备用）
- `customers`：客户列表（备用）
- `summary`：各模块数据数量汇总

### 7.3 数据导入
- **方式**：在「我的」页面点击「选择文件导入」，选择手机上的 JSON 文件
- **规则**：全量覆盖，导入后旧数据全部清除，只保留新导入的数据
- **确认**：导入前弹出确认框，显示数据条数，用户确认后才导入
- **结果**：导入成功后显示成功提示，自动刷新当前页面数据

### 7.4 数据存储
- **存储位置**：浏览器 localStorage
- **存储方式**：每个模块对应一个 key，值为 JSON 字符串
- **持久化**：关闭浏览器、重启手机后数据仍然保留
- **容量限制**：受浏览器 localStorage 限制（一般 5MB 左右，足够几千条记录）

### 7.5 数据清除
- **入口**：「我的」页面 → 「清除所有数据」按钮
- **确认**：二次确认，防止误操作
- **结果**：清除所有本地数据，恢复到初始状态

### 7.6 注意事项
- 清除浏览器缓存/数据会导致数据丢失
- 建议定期从电脑端重新导入最新数据
- 数据只存在当前浏览器中，换浏览器需要重新导入
