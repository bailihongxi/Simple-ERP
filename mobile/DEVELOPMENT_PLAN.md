# 进销存手机版 PWA 开发计划

## 一、总体说明

### 1.1 开发目标
基于 PRD 开发一个可以在手机上使用的 PWA 版进销存查询工具，数据从电脑端导出 JSON 导入，纯只读浏览和筛选。

### 1.2 技术栈
- **前端**：原生 HTML + CSS + JavaScript（不引入框架）
- **存储**：localStorage
- **PWA**：manifest.json + service worker
- **部署**：GitHub Pages
- **测试**：Python unittest（测试 HTML 结构、JSON 数据格式）

### 1.3 开发原则
- 每个功能完成后写测试 → 测试通过 → Git 提交
- 全部完成后运行所有测试验收
- 移动端优先设计，适配手机屏幕

### 阶段0：项目初始化

**目标**：搭建 PWA 基础框架，确保可以正常访问和添加到桌面。

#### 任务0.1：整理目录结构
- **操作**：
  - `mobile/` 目录下创建以下文件：
    - `index.html`（主页面）
    - `manifest.json`（PWA 配置）
    - `sw.js`（service worker）
    - `css/style.css`（样式）
    - `js/app.js`（主逻辑）
    - `js/storage.js`（数据存储封装）
- **产出**：完整的目录结构

#### 任务0.2：编写 manifest.json
- **操作**：
  - name: "进销存"
  - short_name: "进销存"
  - start_url: "./index.html"
  - display: "standalone"
  - background_color: "#ffffff"
  - theme_color: "#3b82f6"
  - icons: 使用简单的 emoji 或 base64 图标（先用简单图标，后续可替换）
- **产出**：manifest.json 文件

#### 任务0.3：编写基础 HTML 结构
- **操作**：
  - 引入 manifest.json
  - 注册 service worker
  - 基础页面结构（顶部栏、内容区、底部导航占位）
  - 引入 style.css 和 app.js
- **产出**：index.html 基础框架

#### 任务0.4：编写 service worker
- **操作**：
  - 缓存静态文件（HTML、CSS、JS）
  - install 事件：预缓存
  - fetch 事件：缓存优先策略
  - activate 事件：清理旧缓存
- **产出**：sw.js 文件

#### 任务0.5：基础样式
- **操作**：
  - 全局样式重置
  - 顶部栏样式
  - 底部导航样式（3个Tab）
  - 基础颜色变量
  - 适配手机屏幕（viewport）
- **产出**：css/style.css 基础样式

### 阶段1：数据存储与导入功能

**目标**：实现 localStorage 数据封装、JSON 文件导入、数据清除功能。

#### 任务1.1：封装 storage.js
- **操作**：
  - `initStorage()` - 初始化（检查 localStorage 可用性）
  - `saveData(storeName, data)` - 保存数据
  - `getData(storeName)` - 读取数据
  - `clearAllData()` - 清除所有数据
  - `setMeta(key, value)` - 设置元数据
  - `getMeta(key)` - 获取元数据
  - 所有函数返回 Promise（保持和之前 IndexedDB 一致的接口）
- **产出**：js/storage.js

#### 任务1.2：JSON 文件导入功能
- **操作**：
  - 文件选择 input
  - 读取文件内容
  - JSON 解析校验
  - 校验必要字段（products、purchases、sales）
  - 导入前确认弹窗（显示数据条数）
  - 全量覆盖写入 localStorage
  - 导入成功/失败提示
- **产出**：导入功能函数

#### 任务1.3：数据清除功能
- **操作**：
  - 清除按钮
  - 二次确认
  - 清除所有 localStorage 数据
  - 清除后刷新页面数据
- **产出**：清除功能函数

#### 任务1.4：数据概览
- **操作**：
  - 统计商品数、采购数、销售数
  - 计算库存总价值
  - 显示导入时间
- **产出**：数据概览函数

#### 测试要点
- [ ] storage 封装函数存在
- [ ] 导入功能代码存在
- [ ] 清除功能代码存在
- [ ] 数据概览代码存在
- [ ] JSON 数据格式校验逻辑存在
- [ ] 导入前确认逻辑存在

## 七、验收标准

全部完成后，满足以下条件即为验收通过：

1. **功能完整**：PRD 中第一版必须完成的功能全部实现
2. **测试通过**：所有单元测试通过
3. **PWA 可用**：可以添加到手机桌面，离线可用
4. **数据正确**：导入数据后各模块显示正确
5. **交互正常**：页面切换、筛选、搜索等操作流畅
6. **只读验证**：没有任何增删改功能

## 八、注意事项

1. **移动端优先**：所有设计以手机屏幕为准，保证触摸操作友好
2. **性能**：数据量大时也要保证流畅
3. **兼容性**：兼容主流手机浏览器（华为浏览器、Chrome、Safari 等）
4. **离线可用**：导入数据后，断网也能正常使用
5. **数据安全**：数据只存在本地，不上传任何服务器
6. **代码规范**：保持代码清晰，注释完善，便于后续维护
